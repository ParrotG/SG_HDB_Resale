# SG HDB Resale 数据探索

使用 Python 3.11 和 uv，按 `docs/Assignment Procedure.pdf` 完成数据获取、质量检查、字段预处理、EDA、享乐价格回归和预处理对比初稿。

## 运行

在项目根目录执行：

```bash
uv sync --locked
uv run jupyter lab
```

打开 `hdb_resale_eda.ipynb`，使用项目 `.venv` 内核并按顺序运行全部单元格。已保存执行输出，可以直接阅读。

## 数据与产物

- `data/raw/hdb_resale_2017_2025.csv`：官方数据截至 2025-12 的快照。
- `data/raw/hdb_resale_2017_2025.metadata.json`：来源、下载时间、日期边界和快照 SHA-256。
- `data/raw/ura_mp2019_planning_areas.geojson`：URA 官方规划区边界，用于 Town 的近似地图展示；附带来源和校验元数据。
- `uv.lock`：锁定本次使用的依赖版本。

默认复用快照。若数据文件不存在，notebook 会通过官方 API 下载并截取；设置 `REFRESH_DATA = True` 可以覆盖刷新，之后应恢复为 `False`。数据源可能回修历史记录，刷新后应复核 notebook 中的固定结论。原始快照及处理结果不纳入 Git。

Notebook 的 Markdown 说明全部使用英文。类别比例使用饼图，小于 1% 的类别仅在图中合并；数值分布使用 Histogram + KDE + 四分位数参考线。各变量与价格的关系图统一放在相关性分析之后。

完全重复的记录共有 308 组：307 组双行、一组三行。主分析保留这些行和 IQR 离群值，另做敏感性比较。租期与近似公式偏差超过 1 年的 128 条记录因原因无法确定而排除，审查记录保留在 notebook 的 `lease_excluded` 中；剩余 221,938 条用于 EDA。

地址采用全局 → Town → Town + Street → Town + Street + Block 的层级平滑 target encoding，演示平滑强度分别为 50、20、10。每年的编码仅使用此前年份的价格；预测比较中 2017 年作为历史预热，2018–2024 为最终训练集，2025 为测试集。地图使用规划区代理边界，未将交易精确定位到住宅单元或规划子区。

清洗、统计、编码与相关性结果保留在 notebook 内存和单元格输出中，不导出处理结果。楼层 ordinal 的 KDE 使用较宽带宽（`bw_adjust=4`），减少整数编码导致的逐层波峰。

享乐价格主回归以对数价格为目标，以 BEDOK 为地区参照，逐步控制登记月份、面积、房型/模型、楼层和租期；标准误按 Town + Street + Block 聚类。地区结果是条件关联，不能直接解释为因果效应。另有 EXECUTIVE 租期调查、残差诊断和清洗敏感性比较。

预测部分使用同一个 OLS 方法逐步比较面积转换、模型类别、楼层类别、租期二次项和历史地址编码。时间趋势仅用 2024 年验证集选择，2025 年测试集用于统一评估；报告 SGD 和对数误差、Town/房型误差，以及训练集去重、租期记录保留/排除和价格 IQR 限制的影响。

完整作业仍需小组复核假设和发现、补充成员贡献并准备视频；notebook 已包含 AI 使用声明和随运行结果生成的讨论初稿。
